# Vita — مساعدك الدراسي الذكي

تطبيق ويب عربي بتصميم داكن مبني بـ Python و Streamlit، يجمع أدوات المذاكرة في مكان واحد:

- 💬 **الدردشة الذكية**: إجابات ذكاء اصطناعي تُكتب مباشرة (Gemini إن وُجد مفتاح، وإلا خدمة مجانية بدون مفتاح).
- 🎨 **السبورة التفاعلية**: رسم بألوان وأحجام مختلفة مع ممحاة وتنزيل اللوحة كصورة.
- 📊 **منشئ الجداول**: جدول مذاكرة قابل للتعديل مع تصدير CSV.
- 📚 **مساعد المستندات**: يقرأ PDF و Word و PowerPoint و Excel والصور (مع التعرف الضوئي على النصوص العربية)، ويصنع ملخصاً وخريطة مفاهيمية واختباراً تفاعلياً يُصحَّح تلقائياً.
- 👤 **الملف الشخصي والإنتاجية**: بروفايل وإحصائيات ومؤقت بومودورو.

## التشغيل محلياً

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## مفتاح Gemini (اختياري)

يعمل التطبيق بدون أي مفتاح. لإجابات أسرع أضف في `.streamlit/secrets.toml` (أو في Secrets على Streamlit Cloud):

```toml
GEMINI_API_KEY = "YOUR_API_KEY"
```

> نسخة تجريبية لمشروع طلابي: الحسابات والبيانات تُحفظ مؤقتاً في جلسة المتصفح فقط.
